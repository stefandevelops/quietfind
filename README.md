# QuietFind

**Real problem:** “Laptop-friendly” cafés and 4-star reviews don’t tell you if you can actually think. You travel across town and sit in a blender of grinders, playlists, and calls.

**Solution:** a no-account finder that ranks places by **hush level** (1 lively → 5 silent), filters for Wi‑Fi and plugs, shows them on a map, and lets you log how quiet it felt when you visited.

## Features

- Curated London starters (libraries, museums, cafés, parks)
- Filters: minimum quiet score, type, Wi‑Fi, plugs, search, favorites
- Map + list sorted by distance when you tap **Near me**
- Save favorites and personal quiet logs (localStorage)
- Add a spot at your current pin
